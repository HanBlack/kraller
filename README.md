# Kraller — životní cyklus bouřek

Interaktivní mapa (**Kraller**) zaměřená na vznik, průběh a útlum bouřek v ČR. Radar ukazuje aktuální srážková echa a jejich vývoj; detail buňky shrnuje první detekci nebo vznik, pohyb, změnu síly a odhad útlumu.

Před vznikem radarového echa lze zapnout samostatnou vrstvu odhadovaných míst vzniku. Jde o doplňující odhad, ne o pozorování radarem. Stav u sledované lokality se zobrazuje jako klidný pouze tehdy, když jsou radarová data dostupná a čerstvá.
